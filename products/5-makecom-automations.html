Automation #1

The Content Machine

Saves 3 hours/week

What it does: You publish one piece of content in one place, and Make.com automatically posts it to TikTok, Instagram, and Twitter/X. No copying. No pasting. No logging into 3 apps. One trigger, three posts, done.

Step-by-Step Setup

  1. Create a new scenario in Make.com. Click the big purple "+" button on your dashboard. Name it "Content Machine."
  2. Add the trigger module: Google Drive > Watch Files. Point it to a specific folder (call it "Ready to Post"). Every time you drop a video file into this folder, the automation fires. Set the schedule to run every 15 minutes.
  3. Add a Router module. Click the "+" after Google Drive and search for "Router." This splits your automation into 3 paths — one for each platform.
  4. Path 1 — Add the TikTok > Upload a Video module. Connect your TikTok account. Map the file from Google Drive to the video field. Add a text file in your Google Drive folder with the caption — use Google Drive > Download a File to pull the caption text and map it to the description field.
  5. Path 2 — Add the Instagram > Create a Reel module. Connect your Instagram Business account. Map the same video file. Map the same caption text. Add up to 30 hashtags in the caption field.
  6. Path 3 — Add the Twitter > Create a Tweet module. Connect your Twitter/X account. Map the video file to the media field. Shorten the caption to 280 characters using the built-in text function: {{substring(caption; 0; 270)}}...
  7. Turn on scheduling. Click the clock icon at the bottom left. Set it to "Every 15 minutes." This means within 15 minutes of dropping a file in Google Drive, it goes everywhere.
  8. Test it. Drop a short test video and a caption.txt file into your "Ready to Post" folder. Click "Run once" in Make.com. Check all 3 platforms. If it works, turn on the scenario and never think about it again.
Pro Tip: Add a 4th path to the Router for LinkedIn. Use the LinkedIn > Create a User Post module. LinkedIn posts with video get 5x more reach than text-only posts, and most creators completely ignore this platform. Same video, zero extra work, whole new audience.

Automation #2

The Comment Closer

Saves 2 hours/week

What it does: Every time someone comments on your YouTube videos, AI reads the comment, writes a helpful reply, and posts it — all within minutes. Your audience feels heard. Your engagement goes up. You do nothing.

Step-by-Step Setup

  1. Create a new scenario called "Comment Closer."
  2. Add the trigger: YouTube > Watch Comments. Connect your YouTube account. Select "All Videos" or pick a specific channel. Set it to check every 15 minutes.
  3. Add a Filter module. Click the wrench icon between YouTube and the next module. Set a condition: comment text does NOT contain "spam" or link URLs. This keeps the bot from replying to junk.
  4. Add the OpenAI (ChatGPT) > Create a Completion module. Connect your OpenAI API key. Set the model to gpt-4o-mini (cheap and fast). Use this prompt in the System Message:
    You are a friendly YouTube creator assistant. Reply to this viewer comment in 1-2 short sentences. Be warm, helpful, and casual. Never be salesy. If they ask a question, answer it. If they give a compliment, thank them. Keep it under 50 words.
    Map the YouTube comment text to the User Message field.
  5. Add the YouTube > Reply to a Comment module. Map the original comment ID from Step 2. Map the AI-generated reply text from Step 4.
  6. Add an Error Handler. Click the small circle at the bottom of the last module. Add a "Resume" error handler. This way, if one comment fails (like a deleted comment), the rest still get replies.
  7. Turn on scheduling at every 15 minutes. Run a test with "Run once." Check your YouTube comments for the reply.
Pro Tip: Add a Google Sheets > Add a Row module at the end. Log every comment and reply to a spreadsheet. After 30 days, you will have a goldmine of audience questions — use those as video topic ideas. The comments literally tell you what to make next.

Automation #3

The Newsletter Ghostwriter

Saves 2.5 hours/week

What it does: Every week, AI writes a full email newsletter based on your latest content and trending topics. It formats it, drops it into your email platform, and either sends it or saves it as a draft for you to review. A complete newsletter in zero minutes of writing.

Step-by-Step Setup

  1. Create a new scenario called "Newsletter Ghostwriter." Set the schedule to once per week (e.g., every Monday at 8 AM).
  2. Add the trigger: RSS > Get RSS Feed Items. Paste the RSS feed URL of your own blog, YouTube channel, or content source. Set the limit to 5 items. This pulls your latest content titles and links.
  3. Add an Array Aggregator module. This collects all 5 RSS items into one bundle so AI can see them all at once. Map the title and link fields from the RSS module.
  4. Add the OpenAI (ChatGPT) > Create a Completion module. Model: gpt-4o-mini. Use this system prompt:
    You are a newsletter writer for IncomeOnAI, a brand that helps creators build income with AI tools. Write a weekly email newsletter. Tone: casual, helpful, like texting a smart friend. Structure: 1) A short intro (2-3 sentences about a relevant theme), 2) "This Week's Top Picks" section with 3 content links and one-line descriptions, 3) One quick actionable tip, 4) A sign-off with "See you next week." Keep it under 300 words. Use line breaks, not HTML.
    Map the aggregated content titles and links to the User Message.
  5. Add the Mailchimp > Create a Campaign module (or use Brevo (Sendinblue) > Create an Email Campaign or ConvertKit > Create a Broadcast depending on your email tool). Map the AI-generated text to the email body. Set the subject line using another short AI prompt or use a template like: "This week in AI: [first content title]".
  6. Set the campaign status to "Draft" (not "Send"). This gives you a chance to review the email before it goes out. Once you trust the system after 3-4 weeks, you can switch it to auto-send.
  7. Add a Slack > Send a Message module (optional). Send yourself a notification: "Your weekly newsletter draft is ready. Go review it." This way you never forget.
  8. Test it. Click "Run once." Check your email platform for the draft. Edit anything that sounds off, then hit send.
Pro Tip: Swap out the RSS module for Google Sheets > Search Rows if you keep a content calendar spreadsheet. Point it to your "Published" column. This way the newsletter always matches exactly what you posted — not just what showed up in your feed.

Automation #4

The Trend Scout

Saves 1.5 hours/week

What it does: Every morning, this automation scans trending topics in your niche, uses AI to turn them into content ideas, and delivers a ready-to-use list to your inbox or Slack. You wake up knowing exactly what to create today.

Step-by-Step Setup

  1. Create a new scenario called "Trend Scout." Set it to run daily at 7:00 AM.
  2. Add the trigger: RSS > Get RSS Feed Items. Add 2-3 RSS feeds from top sources in your niche. For AI/tech content, use feeds from The Verge, TechCrunch, or Hacker News. Set limit to 10 items per feed. You can add multiple RSS modules and connect them all to the next step.
  3. Add a second data source: Google Trends > Get Trending Searches (via the HTTP > Make a Request module). Use this URL: https://trends.google.com/trends/trendingsearches/daily/rss?geo=US. Parse the XML response with the built-in XML parser to extract the top 5 trending topics.
  4. Add an Array Aggregator module. Merge all RSS items and trending topics into one bundle.
  5. Add the OpenAI (ChatGPT) > Create a Completion module. Model: gpt-4o-mini. Prompt:
    You are a content strategist for a faceless AI content brand. Here are today's trending topics and news headlines. Pick the 5 most relevant to the AI tools / make money online / creator economy niche. For each one, give me: 1) The topic in 5 words or less, 2) A TikTok/Reel hook (one sentence, pattern interrupt), 3) A suggested angle that ties it to making money with AI. Format as a numbered list. Be specific and actionable.
    Map the aggregated data to the User Message.
  6. Add a Gmail > Send an Email module (or Slack > Send a Message). Send the AI-generated content ideas to yourself. Subject line: "Your Content Ideas for [today's date]". Map the AI output to the email body.
  7. Add a Google Sheets > Add a Row module (optional). Log every daily idea list to a spreadsheet. After a month, you will have 150+ content ideas you can pull from anytime.
Pro Tip: Add a second HTTP > Make a Request module that pulls data from the Reddit JSON API. Use the URL https://www.reddit.com/r/artificial/.json?limit=10 (swap in any subreddit). Reddit surfaces trends 24-48 hours before they hit mainstream news. You will always be first.

Automation #5

The Stats Courier

Saves 1 hour/week

What it does: Once a week, this automation pulls your key numbers from YouTube, TikTok, and your email list, organizes them into a clean summary, and emails it to you. No logging into 4 dashboards. No spreadsheet updates. Just one email with everything you need to know.

Step-by-Step Setup

  1. Create a new scenario called "Stats Courier." Set it to run every Sunday at 9 AM.
  2. Add the YouTube Analytics > Get Channel Stats module. Connect your YouTube account. Pull: total views (last 7 days), new subscribers, top-performing video, and watch time. These fields are built into the module.
  3. Add the TikTok > Get User Info module. Pull: follower count, total likes, and video count. Note: for detailed TikTok analytics, you may need to use the HTTP > Make a Request module with the TikTok API endpoint and your access token.
  4. Add the Mailchimp > Get List Info module (or your email platform's equivalent). Pull: total subscribers, new subscribers this week, open rate, and click rate from your last campaign.
  5. Add the OpenAI (ChatGPT) > Create a Completion module. Model: gpt-4o-mini. Prompt:
    You are a data analyst for a content creator. Here are this week's stats. Write a short weekly report (under 200 words). Include: 1) A one-line "headline" summary (e.g., "Great week: YouTube up 23%, email list hit 500"), 2) Key wins, 3) One area to improve, 4) One specific action item for next week. Keep it casual and encouraging.
    Map all the stats data to the User Message.
  6. Add the Gmail > Send an Email module. Send the report to yourself. Subject: "Weekly Stats Report — [date range]". Map the AI summary to the body.
  7. Add a Google Sheets > Add a Row module. Log the raw numbers (views, subscribers, email opens) to a spreadsheet. One row per week. After a few months, you will see trends that tell you exactly what is working and what to double down on.
  8. Test with "Run once." Check your inbox for the report. Tweak the AI prompt if the tone is not right. Then let it run every Sunday forever.
Pro Tip: Add a Google Sheets > Search Rows module that pulls LAST week's stats. Feed both weeks into the AI prompt. Now your report includes week-over-week comparisons automatically. "Views up 34% from last week" is way more useful than just "4,200 views."

Prompt 1

The Viral Video Script Engine

Generate 60-90 second video scripts for TikTok, YouTube Shorts, and Instagram Reels

You are a viral short-form video scriptwriter for a faceless AI content channel. TOPIC: [YOUR TOPIC] PLATFORM: [TikTok/YouTube Shorts/Instagram Reels] NICHE: [YOUR NICHE] Write a [60/90]-second video script following this structure: HOOK (first 3 seconds — must create pattern interrupt): - Use one of these proven hook types: [controversial statement / surprising stat / direct question / "stop scrolling if" / "nobody talks about this"] BODY (45-70 seconds): - 3 key points, each introduced with a transition word - Each point = 1 specific, actionable insight (not vague advice) - Include one concrete number or result per point - Weave in [TOOL NAME] naturally as the solution to point #2 CLOSE (10-15 seconds): - Callback to the hook (creates loop) - Clear CTA: [follow for more / link in bio / comment X for the free guide] RULES: - Conversational first-person voice - No emojis in script (narrator reads it) - Write for AI voiceover pacing (short sentences, natural pauses marked with ...) - Every sentence must earn its place — cut anything that doesn't move the viewer forward - Include 1 unexpected analogy or comparison Output the script with [PAUSE] markers and estimated timestamps.
Pro Tip: Run this 3 times with different hook types for the same topic. The best-performing hook becomes your template for that niche.

One CTA per email. - Subject lines: lowercase preferred, question or benefit format - No "Hey [First Name]!" openings. Prompt 4

The Hook Factory

Generate 20 scroll-stopping hooks for any topic

Generate 20 hooks for short-form video content about: [YOUR TOPIC] Create 4 hooks in each of these 5 categories: 1. CONTROVERSY HOOKS ("Everyone is wrong about...") 2. CURIOSITY GAPS ("I found something that...") 3. SOCIAL PROOF HOOKS ("I made $X doing...") 4. FEAR/URGENCY HOOKS ("This changes everything in...") 5. IDENTITY HOOKS ("If you're a [type of person]...") Prompt 5

The Product Description Converter

Generate sales copy for digital products on Gumroad/Shopify

Write a high-converting product description for: PRODUCT: [NAME] PRICE: [PRICE] FORMAT: [PDF / Video Course / Template / Prompt Pack] TARGET BUYER: [WHO AND WHY THEY'D BUY] PLATFORM: [Gumroad / Shopify / Own site] Structure: 1. HEADLINE: Benefit-driven, specific outcome (not features) 2. SUBHEADLINE: Who it's for + timeline to result 3. THE PROBLEM: 3 pain points the buyer feels right now (use "you" language) 4. THE SOLUTION: What this product does differently (not just "what's inside") 5. WHAT'S INSIDE: Bullet list of contents with benefit after each item - [Feature] — [what this means for them] 6. SOCIAL PROOF: Placeholder for testimonial + specific result metric 7. OBJECTION HANDLING: Address top 3 buying objections 8. PRICE JUSTIFICATION: Compare to alternatives (courses, freelancers, trial-and-error) 9. GUARANTEE: Risk reversal statement 10. CTA: Action-oriented button text + urgency element 11. FAQ: 5 common questions with concise answers RULES: - Write at a 6th-grade reading level - Use power words: proven, exact, instant, step-by-step, copy-paste - Price anchoring against expensive alternatives - Scarcity only if genuine (launch pricing, limited bonuses) - Zero hype words: revolutionary, game-changing, amazing, incredible
